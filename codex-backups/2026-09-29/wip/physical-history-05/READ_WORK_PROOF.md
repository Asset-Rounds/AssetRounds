# Scoped physical accounting and work bound v4

This is a source-level derivation, not Swift runtime or independent approval. Root decision 7cb3225 permits only exact positively authenticated typed pairs to charge shared physical payload once. Every alias still has a separate path, node, observed9/full11, SHA, nofollow name, actual device/owner/mode and private policy proof. Ordinary strict helpers are unchanged.

Let U be unique physical regular bytes in one complete admitted tree, A path bytes, F regular namespace members, and B one pair payload. U <= 1GiB, A <= 2U, F < 100000 in a successful tree (directories also count). Ordinary nlink1 leaves contribute B physical/path/own bytes. Exact typed nlink2 members contribute B physical once, 2B path/own bytes. Unproved sharing receives no credit. Aggregate physical U still includes metadata; 1GiB payload plus lease metadata and 4GiB producer ranges remain unresolved representation obligations, not newly accepted states.

Each actual opaque pair PFP invocation has four checked payload streams; canonical current pair has eight. Scanner invokes PFP independently at each alias, preserving proof work. Thus an opaque pair contributes own2B + policy8B =10B payload reads, a current canonical pair own2B + policy16B =18B. Uniform successful payload work <=18U <=18GiB. The exact PFP helper checked-multiplies nonnegative expected byte count and returns payload-only reservation. Each invocation is reserved before its real call; own size is reserved before its stream. The scanner refuses checked overflow or reservation above18GiB before another payload read. Pair invocations <=100000 and declared passes <=800000. Failed partial work is bounded by those pre-IO reservations; no retries or cached authority are used.

Scanner own reads use fixed64KiB pread chunks, exact requested count and finite offset. No EINTR/short-read retry loop exists. Sum ceiling(chunk count) <= floor(A/65536)+F; one EOF probe per file gives at most32768+2*100000 =232768 scanner payload/EOF syscalls. Read-call count is incremented before each call. EOF probes reserve a separate one byte before IO; a changed file can return that byte before refusal. Probe calls/reservations <=100000, so total reserved scanner/PFP reads <=18GiB+100000 bytes. Successful EOF probes return zero. Work receipt reports actual successful payload reads separately from probe reservations; it never calls all failed work exactly18GiB.

Directory enumeration reserves at most100003 readdir calls including dot/dotdot/EOF, <=100000 names per enumeration, and no retry loop. Whole scanner node limit100000 and directory depth64/file depth65 remain; both aliases consume nodes and membership checks. Checked FD/DIR close ownership and permanent uncertain-handle fences remain. Each scoped tree digest now incrementally hashes the exact prior token grammar in traversal order; no full token list/Data image is accumulated. The source-only grammar example checks identical bytes for ASCII, Unicode and empty directories; it does not execute Swift.

The18GiB bound is ONLY this scanner plus explicit PFP payload reads for one scan. It excludes actual issuer/raw complete-census/control/metadata reads and repetitions by the outer complete witness. Each actual scope callback must derive its own nonrecursive finite scan budget. Outer before/after scans multiply the actual per-scan reservation by their real invocation count; no invented2B total, proof omission or cached authorization is allowed. Root/Migration/PFP/Router must complete coupled work reservations before installability.
