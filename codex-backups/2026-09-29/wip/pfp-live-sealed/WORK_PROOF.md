# Actual LIVE PFP work

Let d be the authentic nonempty Operations→immediate-parent ancestor count, B the authentic payload byteCount, and C=ceil(B/65536). Read-work/call products use checked UInt64 arithmetic. No invented per-file/per-tree/global limit is supplied by this API: actual source/role/full-image admission and complete family bounds remain required. The finite retained arrays are authentic selected DATA, not caller authority.

One selected pair invocation performs FOUR complete SHA streams on the first UTF8ordered alias: before and after each of the two actual policy reads. Both names/held descriptors and the entire ancestor chain are reproved around every stream chunk and policy primitive. Shared inode does not cache acceptance or remove proof. Exact successful payload bytes=4B and pread calls=4C; the context checks those actual totals. B=0 still finalizes/compares the real empty digest for each stream.

A single-node observation performs no PFP payload stream: its genuine source/whole raw scan separately authenticates payload. It executes one resourceValues, one FileManager attributes call and one named lstat, each under full typed held/named proofs. A pair executes those three calls for EACH alias. Success opens and closes d+1 descriptors for single, d+2 for pair. Opens are no-follow and each fd lifetime is retained before post-open proof.

For each complete held/named proof, PFP issues H=2(d+leafCount) raw stat calls. Successful single observation issues16(d+1) raw stat calls, plus3 metadata calls and d+1 opens/closes each. Successful pair issues H*(19+8C) raw stat calls with leafCount2, plus6 metadata calls,4C preads and d+2 opens/closes each. Every raw primitive has fresh actual Scope/selected membership callbacks before/after. Those callbacks' own nonrecursive control/owner IO is SEPARATE and must be derived by its actual module; no repeated whole payload scan is permitted per primitive.

Setter always issues TWO actual Foundation mutation calls, in protection→backup order. Files stream the actual prefix SHA twice (before first mutation and after final private readback): exact2B payload bytes/2C preads checked. Directory setters have nil sourceSHA/count and no payload stream; the fixed engine currently has no directory-birth request, so no invented checkedBirth role is issued. One final three-primitive policy reader preserves the exact ordinary strict/qualified Simulator predicate. Pending Simulator requests additionally use one actual pre-request capability query and unchanged diagnostic transport; those diagnostic and Foundation internal costs are separate actual implementation work, not a fabricated syscall count.

Setter PFP raw stats on success are bounded by2d+(23+4C)*2(d+1) for files (conservative DEBUG pending route), plus d+1 opens/closes each,2C preads,2 setters and at most4 selected metadata queries. For directories the conservative bound is2d+21*2(d+1). NonDEBUG/strict routes do less. Error cleanup is a finite prefix of these operations plus one close per still definitely-owned slot; no retry loop is added. Held ambiguity permanently fences its slot instead of adding a close/reinspect.

These are PFP-local counts only. Raw full-image passes, outside-image proof, canonical source capture/catalog, issuer/control/Registry/EX/work, Foundation internal queries, diagnostic transport, and actual OS behavior require independent genuine finite bounds and runtime evidence. Four streams is not the full family cost. No whole1GiB Data copy or producer payload canonicality assertion is introduced by these streaming readers.
