| --- | --- | --- |
| Exact Ledger-issued fixed current final/.partial role; canonical nonempty bytes; full11 facts; nlink2 shared inode; mode0600/euid/actual parent-derived GID/device; strict complete policy | Returns two equal temporal observations after all exact reads/reproofs and checked closes. This is observation data only; no ordinal/progress authority. | NOT RUN |
| Same exact role and identity with exact incumbent DEBUG iOS Simulator unsupported fallback | Returns pendingSimulatorRequest observations only under the unchanged private predicate. No setter, success disposition or accepted protection. | NOT RUN |
| Same fallback on non-DEBUG/physical route | Refuses through unchanged strict private predicate. Physical protection remains unverified. | NOT RUN |
| Ordinary unassigned path or caller-selected pair/ordinal/operation/plan/Store stage | Scope cannot issue/admit the pair; refuses. No generic nlink2 exemption. | NOT RUN |
| Different caller URL representation, wrong deterministic partial name, wrong parent, wrong final role or empty canonical payload | Refuses before file opens, then permanently terminally fences attempt and poisons operation. | NOT RUN |
| Two different inodes, nlink1/3+, extra link elsewhere, wrong UID/GID/mode/device/size or any one of the11 fields differs | Refuses after exact held/named comparison; each still-owned FD has one checked terminal close. | NOT RUN |
| Same-inode substitution, changed parent, renamed name, symlink or path/held mismatch | Nofollow parent/openat pins and exact named/held/fullfact checks refuse. | NOT RUN |
| Canonical byte drift before, during or after policy metadata read | Exact bounded pread comparison of both held aliases plus repeated fullfact/name/parent proof refuses. | NOT RUN |
| ResourceValues/FileManager/lstat failure or policy mismatch | Fresh binding is checked after failed IO too; refuses and checked-closes acquired slots. | NOT RUN |
| Parent/final/partial open fails | Attempt was retained before first IO; successful earlier opens are checked-closed once; failed open has no owned FD. | NOT RUN |
| Scope revoked/EX-G-operation/currentStore-plan-stage/local-lineage binding fails before/after read or close | Refuses and poisons real operation. Each owned slot is terminally fenced and attempted once for cleanup; no more observation IO. | NOT RUN |
| Close fails, including ambiguous kernel close/EINTR | Attempt permanently uncertain before callback; exact operation is poisoned before supplied owner callback. Raw uncertain FD stays evidence only; no later inspection/retry/deinit close. Remaining separately owned slots close once. | NOT RUN |
| Close succeeds then post-close proof fails or numeric FD is reused | Slot was removed before close; no cached numeric FD is ever inspected/reclosed. Attempt remains terminal and operation is poisoned. | NOT RUN |
| A supposedly new open aliases an already held numeric FD | Alias becomes permanently uncertain; duplicate is removed from usable slots, exact operation is poisoned before retention callback, no ambiguous alias close. Other definitely owned slots close once. | NOT RUN |
| Escaped attempt after success/error/body exit | Private slots/memory terminal fence and absent deinit closer prevent further use/retry. Scope owner retains it through current operation lifetime. | NOT RUN |
| Exact reserved zero/prefix publication cut | This pair API does not admit it. Ledger/Factory separately observes unacceptedEmptyPublication/publicationPrefix from exact fixed role; no empty-as-policy or empty-as-progress assertion. | NOT RUN |
| Legacy one-link observation, unchecked ordinary pair helper, existing DEBUG Simulator request/notification/producer callbacks/fd0a or Release policy | Their bodies remain byte-identical. The existing private reader gets only a default-nil read-only callback; policy predicates/default behavior remain unchanged. | Source binding only; runtime NOT RUN |
