# SOURCE-ONLY / WIP archival checkpoint

This branch is a backup, not an integration candidate. Its top-level app is the published bcc9844 checkpoint. The `codex-backups/2026-09-29` prefix holds explicitly scoped immutable source snapshots, unfinished helper work, context, and working records. WIP is incomplete and noninstallable; syntax-only reports do not prove compilation. Nothing here advances main, constitutes gate evidence, or authorizes release. Later live edits remain protected locally until another checkpoint.

`MANIFEST.json` binds every archived file's original absolute path, SHA-256, Git blob, raw byte length, and POSIX mode. Historical INPUTS manifests are included and checked. Directories and empty-directory metadata are recorded. Git reuses existing objects; no second working checkout is needed. This archive does not contain the 136GiB native evidence or build products, which remain locally retained.

To recover a scope, obtain this commit from GitHub, place its archived `root-backup-tools/archive.py` and `MANIFEST.json` together in a root-owned packet, and run `archive.py restore --repo /absolute/git/repo --revision BACKUP_COMMIT --scope SCOPE_KEY --destination /absolute/new/empty/path`. `MANIFEST.json` identifies scope keys and original restoration paths. The destination must not exist. Verify output before transferring recovered files to their original historical source location; never overwrite owner drafts or current work. Do not rerun old run.py scripts: they may overwrite retained originals.

Restore covers raw source bytes and POSIX permissions. It does not recreate Finder/document IDs, ownership, ACLs or extended attributes. Historical flagged `.codex/config.toml` and its original parent remain locally preserved. All original outer evidence/manifests/logs/Products/modules and all active helper packets remain in place. Cleanup is limited to reviewed exact obsolete source-copy children after independent review, a non-force push and fresh remote closure verification.
